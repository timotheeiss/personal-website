A Semantic Representation Layer for Autonomous Testing Agents

A way to make web interfaces easier and cheaper for AI agents to test by giving them compact, purpose-built descriptions of what is on the page.

About the research

Autonomous testing agents can verify a web app by using it through a browser, but conventional page representations give them more detail than each task needs. My thesis presents Semtag: a small vocabulary of data-semtag-* attributes that describe an element’s role, identity, state and target. An extractor turns these hints into a compact semantic snapshot for the agent.

I compared a hinted agent with an accessibility-snapshot baseline over 840 runs on 14 AI-generated applications and three models. The hinted agent used accessibility snapshots as a fallback when needed.

  • Semantic snapshots were 69% smaller on average than accessibility snapshots of the same page.
  • On Claude Sonnet 5 and Opus 5, per-run API cost fell by 15.9% and 12.6%, while precision, recall and F1 stayed within three points of the baseline and latency was unchanged.
  • On Claude Haiku 4.5, there was no cost saving; F1 was ten points higher, though that difference was not statistically significant across the 14 applications.
